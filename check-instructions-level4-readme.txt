<p>Простий модуль доставки для OpenCart. Ядро OpenCart не змінювалось — інтеграція з чекаутом зроблена через OCMOD (див. нижче), стандартний shipping-модуль (<code>getQuote</code>) і два AJAX-ендпоінти пошуку.</p>

<h4>Що реалізовано</h4>
<ul>
  <li>Сторінка налаштувань в адмінці: API-ключ (необов'язковий), три типи доставки — у відділення / адресна доставка кур'єром / у поштомат, кожен з окремим перемикачем увімк./вимк. і своєю вартістю, загальний статус модуля, порядок сортування.</li>
  <li>Метод доставки "Нова Пошта" виводиться в чекауті поряд зі стандартними методами, окремим пунктом на кожен увімкнений тип доставки.</li>
  <li>Поля <b>місто</b> та <b>відділення/поштомат</b> — це стандартні поля адреси доставки (<code>city</code>/<code>address_1</code>), з яких прибрано зайве (компанія, другий рядок адреси, індекс, область). Якщо в налаштуваннях вказано API-ключ Нової Пошти — ці поля перетворюються на live-автодоповнення по реальному API, з кешуванням результатів. Без ключа — звичайні текстові поля, доставка лишається робочою.</li>
  <li>Поле <b>коментар</b> — стандартне поле "Коментар до замовлення" OpenCart, окреме дублювання прибрано зі способу доставки.</li>
  <li>Кешування відповідей API (міста/відділення) через стандартну бібліотеку Cache OpenCart.</li>
  <li>Логування помилок звернень до API Нової Пошти в <code>system/storage/logs/novaposhta_api.log</code>.</li>
  <li>Мультимовність: uk-ua та en-gb для адмінки і каталогу.</li>
</ul>

<h4>Файли модуля</h4>
<ul>
  <li><code>system/library/novaposhta.php</code> — клієнт API Нової Пошти.</li>
  <li><code>admin/controller/extension/shipping/novaposhta.php</code> — сторінка налаштувань модуля.</li>
  <li><code>admin/view/template/extension/shipping/novaposhta.twig</code></li>
  <li><code>catalog/model/extension/shipping/novaposhta.php</code> — розрахунок вартості доставки.</li>
  <li><code>catalog/controller/extension/shipping/novaposhta.php</code> — AJAX-ендпоінти автодоповнення.</li>
</ul>

<h4>Встановлення</h4>
<ol>
  <li>Скопіювати файли модуля у відповідні директорії проєкту.</li>
  <li>В адмінці: Розширення → Доставка → знайти "Нова Пошта" → Встановити.</li>
  <li>Відкрити налаштування модуля, за потреби вказати API-ключ Нової Пошти, вартість/зону/статус → Зберегти.</li>
  <li>Застосувати кастомізацію чекауту через OCMOD (див. нижче).</li>
  <li>На сторінці оформлення замовлення обрати метод "Нова Пошта".</li>
</ol>

<h4>Кастомізація чекауту (OCMOD)</h4>
<p>Через OCMOD (<code>system/ecoplastics_checkout.ocmod.xml</code>) — без правок файлів ядра на диску. Чекаут переписаний в одну статичну сторінку з дев'ятьма полями: ім'я, прізвище, email, телефон, спосіб доставки, місто, адреса доставки (з автодоповненням Нової Пошти), спосіб оплати, коментар. Єдина дія користувача — кнопка "Оформити замовлення" внизу, яка послідовно виконує весь стандартний ланцюжок кроків OpenCart за лаштунками.</p>
<p>Щоб активувати: <b>Marketplace → Modifications → Refresh</b> в адмінці.</p>

<h4>Інша кастомізація адмінки (OCMOD)</h4>
<p><code>system/ecoplastics_dashboard.ocmod.xml</code> — вимикає попередження про небезпечне розташування каталогу system/storage на дашборді (актуально тільки для цього тестового оточення).</p>
